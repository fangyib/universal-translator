# Universal Translator · 万物翻译机

Hackathon frontend for the Universal Translator track.

Open `index.html` in a browser, or serve the folder:

```bash
python -m http.server 5173
```

Then visit `http://127.0.0.1:5173/`.

## Layout

- `index.html` — page shell
- `css/` — theme, landscape, sidebar, chat, composer, overlays
- `js/` — particles, state, mock translator, UI, interactions

Mock replies live in `js/translator.js`. Replace that file when the backend is ready.
